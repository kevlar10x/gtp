# Changelog

## Unreleased

- The plugin's directory listing now links to the README and has more search keywords.
- SKILL.md now names its home repo, so a copied skill still points back to the original.
- The plugin marketplace is now called `kevlar10x-gtp`. It was `kevlar10x`, the same name quiet-transcript uses, so adding both made one replace the other.

## 1.0.0 - 2026-10-26

- First release. Say `gtp` and Claude asks what a would-be player, user or downloader would ask about your project, answers from what's actually there, and fixes the gaps it can.
- Install it with `npx skills add kevlar10x/gtp -g`, as a Claude Code plugin with `/plugin install gtp --marketplace kevlar10x/gtp`, or by uploading `gtp.zip` from the release to claude.ai.
- The README shows a real run on a made-up app, with a note that the demo's fixes are only suggestions because that app had no files.
